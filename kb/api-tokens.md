# API-токени та доступ до API

API Звітографа дозволяє отримувати дані звітів і керувати ними з ваших програм та скриптів.

Як створити токен:

1. Відкрийте «Профіль → API-токени» і натисніть «Створити токен».
2. Дайте токену зрозумілу назву, наприклад «Інтеграція з CRM».
3. Оберіть області доступу: лише читання або читання і запис.
4. Задайте термін дії: 30 днів, 90 днів, рік або безстроково.
5. Скопіюйте токен одразу: після закриття вікна його не можна буде побачити знову.

Використання. Передавайте токен у заголовку кожного запиту: `Authorization: Bearer <токен>`. Токен має ті самі права, що й користувач, який його створив.

Ліміти. API приймає до 100 запитів на хвилину на один токен. Якщо ліміт перевищено, сервер повертає код 429; повторіть запит через кілька секунд.

Безпека. Не зберігайте токени у відкритому коді та не надсилайте їх поштою. Якщо токен міг потрапити до сторонніх, негайно відкличте його кнопкою «Відкликати» і створіть новий. Адміністратор бачить усі токени робочого простору і може відкликати будь-який із них.
